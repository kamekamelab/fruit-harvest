# くだもの収穫

森の果物とカラス、畑の野菜とうさぎを選び、みんなで16個の作物を集める協力ゲームです。

- [ブラウザで遊ぶ](https://kamekamelab.github.io/fruit-harvest/)
- WindowsのMicrosoft Edge / Google Chromeと横長の大型タッチ画面を想定
- インターネット接続なしで使う場合は、[Releases](https://github.com/kamekamelab/fruit-harvest/releases)からHTMLをダウンロードして開く

生徒ごとにマウス・タッチ／共有スイッチ（右クリック）を設定できます。1台のマウスとスイッチを順番に使い、先生が操作や順番を管理できます。

スイッチの収穫は先生と相談して、タッチ・左クリックで光る候補を選んでから本人が押して確定します。タッチ／ドラッグ等の方法は今の人と順番欄で確認できます。ドラッグでは、かごを隠さない枠と「↑ ここに はこぼう」で運び先を示します。

森ではタッチか、かごへのドラッグ。畑では葉っぱなどを上へ引いて収穫します。畑の配置は新しいゲームごとに変わり、共有スイッチでは従来どおり1押しで操作します。先生用の入口は設定画面にあります。

畑は指を離さず、少し上へ引くと収穫できます。ドラッグは最初の指を保ち、点線枠のどこで離してもかごへ入ります。順番確認から戻るとサイコロがゆっくり明滅して案内します。

先生の画面を開くと進行・演出・音を一時停止します。「できた！」の表示時間を調整でき、音を切っていても選び間違いが分かる案内があります。

この公開リポジトリには配布用の生成済みアプリだけを収録しています。現在の版と成果物SHAは[配布manifest](release-manifest.json)を参照してください。アプリの設定画面末尾の「Licenses」から、第三者コードのライセンスを確認できます。

独自制作部分には、一般公開用のオープンソースライセンスを設定していません。
